## Abstract

The Intelligent Job Portal is a smart job-search system designed to help applicants find relevant job opportunities efficiently. It uses Data Structures and Algorithms for skill- and location-based searching and ranking. Hashing and Trie structures provide fast indexing and searching, while set intersection combines multiple filters. A Max Heap ranks jobs based on relevance, helping users find suitable opportunities quickly. The system also supports autocomplete and scalable searching for large job datasets.

## Data Structures & Algorithms

* **Hashing** – Fast indexing and lookup
* **Trie** – Skill and job-title search/autocomplete
* **Set Intersection** – Combined filtering
* **Max Heap** – Relevance-based ranking
* **String Matching** – Searching within job corpus
